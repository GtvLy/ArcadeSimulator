# 街机模拟器（Arcade Simulator）设计文档

> 本文档为游戏设计层面的完整说明，涵盖游戏概念、场景流程、小游戏玩法、美术/音频资源与操作说明。

## 1. 项目概述

**街机模拟器（Arcade Simulator）** 是一款像素风格的街机模拟游戏。玩家扮演一名在夜晚街道上行走的角色，可以进入街机厅，在 6 个街机机台中挑选并游玩 5 款风格各异的复古小游戏。项目本身定位为「大学 C++ 课程作业」，因此更侧重展示 C++ 面向对象编程、SFML 图形/音频编程、状态机与游戏系统设计等能力。

### 1.1 设计目标

- 搭建一个可复用的 **场景管理框架**（主菜单 → 街道 → 街机选择）。
- 通过抽象基类 `GameBase` 统一 5 款小游戏的接口，便于扩展新的小游戏。
- 展示多种经典游戏玩法：格斗、竞速、平台跳跃、第一人称迷宫、贪吃蛇。
- 所有美术与音效资源均由作者独立制作（绘制 + 程序化生成音效）。

## 2. 核心玩法与流程

### 2.1 整体流程

```
主菜单 (Scene1)
   │  点击「开始游戏」
   ▼
街道场景 (Scene2)  ──按 F（进入街机）──▶  街机选择 (Scene3)
   │                                          │ 选择 1–6 号游戏
   │◀──────────────返回（Q / 按钮）────────────┤
   │                                          ▼
   │                                     小游戏 (Game1–Game5)
   │                                          │ Q / ESC 退出
   └───────────────────────────────────────────┘
```

### 2.2 设计要点

- **分辨率**：逻辑分辨率固定为 **320×180**（复古像素比例），窗口实际为 1280×720（4 倍缩放），通过 `sf::View` 的 viewport 实现等比缩放与居中（黑边 letterboxing）。
- **帧率**：锁定 60 FPS。
- **场景切换**：`SceneManager` 持有所有场景，通过「请求切换 + 检查切换」的两阶段机制避免在事件处理过程中立即销毁场景。
- **资源管理**：单例 `ResourceManager` 缓存纹理、字体、音效、音乐，避免重复加载。

## 3. 场景设计

### 3.1 场景一：主菜单（Scene1）

- **背景**：`assets/images/scene1/bg.png`
- **背景音乐**：`assets/audio/night.ogg`（循环）
- **交互元素**：
  - 「开始游戏」按钮 → 切换到 Scene2
  - 「帮助」按钮 → 显示帮助页面（`help.png`），内有「返回」按钮
- **按钮状态**：Off（默认）/ On（悬停）/ Click（点击）三态，各对应一张图片。

### 3.2 场景二：街道场景（Scene2）

这是游戏的主枢纽场景，玩家可以自由行走。

- **场景尺寸**：483×180（横向卷轴，比屏幕 320 宽）。
- **背景**：`bg.png`（街道）+ `light.png`（灯光叠加层，营造夜晚氛围）。
- **背景音乐**：`assets/audio/city.ogg`（循环）。
- **玩家**：使用 `main_Idle.png`（9 帧站立）与 `main_Walk.png`（12 帧行走）精灵表，`A/D` 键左右移动，屏幕显示大小约 32×32。
- **NPC**：`NPCManager` 定时从屏幕两侧生成路人（两种外观 `npc1`、`npc2`），随机方向行走，离开屏幕后移除；与玩家重叠时 NPC 会逐渐半透明化（虚化）。
- **摄像机**：跟随玩家水平移动，并被限制在场景边界内。
- **街机入口**：玩家走到 X 轴 **240–300** 区间时，头顶出现 `F` 键交互提示（`F_off.png` / `F_button.png`），按下 `F`（或点击提示）切换到 Scene3，同时播放 `coin.ogg`。
- **返回**：左上角返回按钮或 `Q` 键回到主菜单。

### 3.3 场景三：街机选择（Scene3）

- **背景**：`assets/images/scene3/bg.png`
- **交互元素**：6 个游戏按钮（`game1` ~ `game6`），排列为 2 行 × 3 列，每个按钮同样有三态图片。
- **返回**：右上角返回按钮或 `Q` 键回到街道场景。
- **游戏选择逻辑**：
  | 按钮 | 对应游戏 | 类型 |
  | --- | --- | --- |
  | 1 | Game1 | 格斗（街霸） |
  | 2 | Game2 | 赛车 |
  | 3 | Game3 | 超级马里奥 |
  | 4 | Game4 | 3D 迷宫 |
  | 5 | Game5 | 贪吃蛇 |
  | 6 | （未实现） | 预留 / TODO |

  > 注：第 6 个按钮已存在但未绑定具体游戏，点击后进入「TODO」分支，无实际游戏。

## 4. 小游戏设计

所有小游戏均继承自抽象基类 `GameBase`，实现 `init / handleInput / update / render / isGameRunning / isGameOver / getScore / reset` 接口。统一的退出方式：`Q` 键或点击左上角返回按钮（内部将游戏置为暂停态，由 Scene3 检测到「非运行且非结束」后返回选择界面）。

### 4.1 游戏 1：格斗游戏（街霸风格）

- **类型**：2D 横版格斗，玩家 vs AI。
- **角色属性**：生命值 300、气槽 0–100（自动缓慢恢复，攻击命中可增加）。
- **回合制**：三局两胜（先取得 2 回合胜利者胜出）；每回合 99 秒，超时按血量判胜。
- **玩家操作**：
  | 按键 | 动作 |
  | --- | --- |
  | `A` / `D` 或 `←` / `→` | 前后移动 |
  | `W` / `↑` | 跳跃 |
  | `S` / `↓` | 下蹲 / 防御（格挡） |
  | `J` | 轻拳（伤害 5） |
  | `K` | 重拳（伤害 12） |
  | `U` | 轻腿（伤害 7） |
  | `I` | 重腿（伤害 15） |
  | `L` | 必杀技（消耗 50 气，伤害 25） |
- **AI**：每 0.3 秒根据「与玩家距离 + 自身血量」决策：血量低时防守反击，血量健康时主动进攻，气满时概率释放必杀技。
- **系统特性**：
  - 攻击判定框（Hitbox）系统，格挡成功会播放格挡音效并产生火花。
  - 连击计数（Combo）与显示，连击数越高显示越大/颜色越炫。
  - 粒子特效（普通 / 火焰 / 冲击波 / 血液四种类型）。
  - 摄像机震动（受击与必杀技时）。
  - 受击后的短暂无敌帧、击退、倒地（KO）状态。
  - 程序化音效（拳、脚、受击、必杀、KO、格挡，均通过波形生成，无需外部音频文件）。

### 4.2 游戏 2：赛车游戏

- **类型**：伪 3D 纵卷轴竞速。
- **规则**：3 秒倒计时后开始，比赛时长 **60 秒**，结束后显示最终排名与分数。
- **玩家操作**：
  | 按键 | 动作 |
  | --- | --- |
  | `←` / `→` 或 `A` / `D` | 左右转向 |
  | `↑` / `W` | 加速（最高 200） |
  | `↓` / `S` | 刹车 / 减速 |
- **系统特性**：
  - 玩家红车 + 5 辆不同颜色的 NPC 赛车，NPC 会随机变道、互相避让。
  - 基于 `z` 深度的透视缩放（`getPerspectiveScale`），远景物体更小。
  - 赛道滚动、中心虚线、路面条纹、两侧红白护栏、路旁树/路标/建筑装饰。
  - 尾气粒子、碰撞火花粒子、引擎脉冲与速度光效。
  - 实时显示速度、时间、排名、分数。

### 4.3 游戏 3：超级马里奥（平台跳跃）

- **类型**：横版卷轴平台闯关。
- **规则**：玩家从起点出发，向右前进，到达 X ≥ 800 的终点即通关；生命值 3 颗心，掉出屏幕底部或生命归零则游戏结束。
- **玩家操作**：
  | 按键 | 动作 |
  | --- | --- |
  | `A` / `D` 或 `←` / `→` | 左右移动 |
  | `Space` / `W` / `↑` | 跳跃 |
- **关卡元素**：
  - 地面砖块、普通砖、问号砖（顶出蘑菇/火焰花）、管道。
  - 敌人：蘑菇怪（Goomba）、乌龟（Koopa），踩头可消灭并获得分数。
  - 金币：收集 +10 分并计数。
  - 道具：蘑菇（恢复 1 点生命）、火焰花（+200 分）。
- **系统特性**：完整 AABB 碰撞（分离轴方向判断）、摄像机平滑跟随、粒子特效、程序化音效（跳跃 / 金币 / 受击 / 道具）。

### 4.4 游戏 4：3D 迷宫（光线投射）

- **类型**：第一人称迷宫，基于 Raycasting（射线投射）渲染伪 3D 画面。
- **规则**：从起点 (1.5, 1.5) 出发，找到地图中的终点（金色脉冲墙面）即胜利，记录通关时间。
- **玩家操作**：
  | 按键 | 动作 |
  | --- | --- |
  | `W` / `S` | 前进 / 后退 |
  | `A` / `D` | 左右平移 |
  | `←` / `→` | 旋转视角 |
- **系统特性**：
  - 16×16 网格地图，80 条射线、60° 视野（FOV）、最大深度 20。
  - 墙面按位置显示红/绿/蓝/黄多色，并根据距离与「水平/垂直墙面」调整明暗（距离越远越暗、水平墙面更暗）。
  - 鱼眼畸变校正（`distance *= cos(rayAngle - player.angle)`）。
  - 右上角小地图显示地图、玩家位置与朝向。
  - 天花/地板分色，终点墙面脉冲闪烁。
  - 屏幕实时计时器。

### 4.5 游戏 5：贪吃蛇（增强版）

- **类型**：网格贪吃蛇，加入了大量现代增强元素。
- **网格**：40×22，每格 8 像素（适配 320×180 分辨率）。
- **规则**：吃食物增长并加分，撞墙 / 撞自己 / 撞障碍物 / 撞敌人则游戏结束。
- **玩家操作**：
  | 按键 | 动作 |
  | --- | --- |
  | `↑` / `↓` / `←` / `→` | 改变蛇的移动方向 |
  | `Shift`（左/右） | 加速（按住时移动间隔减半） |
  | `M` | 开关音效 |
- **系统特性**：
  - 多种食物（5 个）脉冲发光。
  - 敌人（最多 8 个）：红色「漫游型」随机移动、橙色「追踪型」追逐蛇头；蛇身撞击敌人可消灭并加分。
  - 障碍物（最多 15 个）：三种颜色/类型，旋转 + 发光。
  - 道具（3 种）：**加速**（青色）、**无敌**（金色，可穿过敌人）、**幽灵**（绿色，可穿墙）。
  - 拖尾光轨、粒子系统、蛇身渐变色（紫→浅紫 5 段渐变）、蛇头眼睛。
  - 程序化音效（吃食 / 道具 / 受击 / 游戏结束 / 移动）。
  - 蛇身被蛇头撞到敌人等交互逻辑。

## 5. 操作说明（完整版）

## 8. 已知问题 / 未完成项

- 第 6 号街机游戏按钮未绑定实际游戏（点击后进入 TODO 分支）。
- `Scene3::selectGame` 中存在日志文本复制粘贴错误：选择 Game1 时日志输出为 "Game3 (Mario) started!"，选择 Game3 时同样输出 "Game3 (Mario) started!"（不影响功能，仅日志不准确）。
- `Game3::updatePlayer` 中存在一处重复的 `return;`（无害冗余）。
- 代码中存在较多调试日志输出（`std::cout << "[DEBUG]..."`），正式发布时可考虑移除或降级。
- `TestScene`、`TestSpriteScene` 两个测试场景未接入主流程（保留在源码中，用于开发期调试）。
