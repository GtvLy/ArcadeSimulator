# 街机模拟器（Arcade Simulator）技术文档

> 本文档为技术实现层面的完整说明，涵盖技术栈、架构设计、类设计、核心系统与构建指南。

## 1. 技术栈与运行环境

| 项目 | 说明 |
| --- | --- |
| 语言 | C++（C++11/17 特性，如 `std::unique_ptr`、`std::function`、lambda、`override`） |
| 图形/音频库 | SFML 2.x（`sfml-graphics-2`、`sfml-audio-2`、`sfml-window-2`、`sfml-system-2`） |
| 音频扩展 | OpenAL（`openal32.dll`） |
| 编译器 | MinGW-w64（运行依赖 `libgcc_s_seh-1.dll`、`libstdc++-6.dll`、`libwinpthread-1.dll`） |
| 平台 | Windows |
| 逻辑分辨率 | 320×180（窗口 1280×720，4 倍缩放，letterbox 居中） |
| 帧率上限 | 60 FPS |

## 2. 架构总览

项目采用 **分层 + 状态机** 架构：

```
main.cpp
   └── Game                         // 顶层游戏类：窗口、主循环、视图缩放
         └── SceneManager            // 场景管理器：持有并切换场景
               ├── Scene1            // 主菜单
               ├── Scene2            // 街道场景
               └── Scene3            // 街机选择
                     └── GameBase    // 小游戏抽象基类
                           ├── Game1 // 格斗
                           ├── Game2 // 赛车
                           ├── Game3 // 马里奥
                           ├── Game4 // 3D 迷宫
                           └── Game5 // 贪吃蛇
```

**支撑组件（被多个模块复用）**：

- `ResourceManager`：单例资源缓存（纹理/字体/音效/音乐）。
- `SpriteSheet`：精灵表逐帧动画。
- `Button` / `SpecialButton`：通用 UI 按钮（三态 / 按键触发）。
- `Camera`：带边界约束与跟随的 2D 摄像机。
- `Player`：街道场景主角（状态机 + 精灵动画）。
- `NPC` / `NPCManager`：路人 NPC 及其生成/管理。
- `GameBase`：小游戏统一接口。

### 2.1 主循环

`Game::run()` 执行经典的固定顺序主循环：

```cpp
while (running && window.isOpen()) {
    processEvents();  // 处理事件（含场景切换请求检查）
    update();         // 计算 deltaTime，更新当前场景
    render();         // 清屏 → 应用视图 → 渲染当前场景 → 显示
}
```

- `processEvents()` 中，事件先由 `SceneManager::handleInput` 分发给当前场景，再调用 `SceneManager::checkSceneChange()` 统一处理场景切换请求。
- `update()` 通过 `sf::Clock::restart()` 计算帧间隔 `deltaTime`。
- 窗口缩放时通过 `updateScale()` 重新计算 viewport，保持 320×180 逻辑分辨率等比缩放并居中。

## 4. 核心类设计

### 4.1 `Scene`（场景基类）

抽象基类，定义所有场景的统一接口：

- 纯虚函数：`handleInput` / `update` / `render`。
- 生命周期：`onEnter()` / `onExit()`。
- 场景切换：`requestSceneChange(SceneType)` 设置 `nextScene` 与 `shouldChangeScene` 标志，由 `SceneManager` 在事件处理结束后统一切换。`isChangingScene` 标志防止重复请求。

`SceneType` 枚举：`None / Scene1 / Scene2 / Scene3`。

### 4.2 `SceneManager`（场景管理器）

- 用 `std::map<SceneType, std::unique_ptr<Scene>>` 持有所有场景。
- `addScene` 注册场景；`changeScene` 执行「退出旧场景 → 进入新场景」。
- `update` / `render` / `handleInput` 委托给当前活跃场景。
- `checkSceneChange()` 检查当前场景的切换请求并执行。

### 4.3 `GameBase`（小游戏抽象基类）

小游戏的统一接口，`Scene3` 通过基类指针 `std::unique_ptr<GameBase> currentGame` 多态调用：

```cpp
virtual void init() = 0;
virtual void handleInput(const sf::Event&, sf::RenderWindow&) = 0;
virtual void update(float deltaTime) = 0;
virtual void render(sf::RenderWindow&) = 0;
virtual bool isGameRunning() const = 0;
virtual bool isGameOver() const = 0;
virtual int getScore() const = 0;
virtual void reset() = 0;
```

退出机制：小游戏的返回按钮 / `ESC` 将内部 `gamePaused` 置为 `true`；`Scene3` 检测到 `!isGameRunning() && !isGameOver()` 时，销毁游戏实例并返回街机选择界面。

### 4.4 `ResourceManager`（资源管理器）

- **单例**（Meyers 单例，`getInstance()` 返回静态局部实例）。
- 四类缓存：`std::map<std::string, sf::Texture/Font/SoundBuffer>` 与 `std::map<std::string, std::unique_ptr<sf::Music>>`（`sf::Music` 不可拷贝，需用指针）。
- `loadXxx` 先查缓存，命中则直接返回；未命中则加载并缓存。
- 纹理加载失败时会生成一个 10×10 红色纹理作为错误占位，避免崩溃。
- 所有资源路径使用 `../assets/...` 相对路径（相对于 `bin/` 工作目录）。

### 4.5 `SpriteSheet`（精灵表动画）

- 加载单行水平排列的精灵表，按帧宽/帧高切分纹理区域。
- `update(deltaTime)` 累积时间并按 `frameTime`（= 1/fps）推进当前帧；支持循环播放或停在末帧。
- `play / pause / stop / reset` 播放控制。
- `setFlipX` 通过负缩放实现水平翻转（中心原点时无需调整位置）。
- `setColor` 支持颜色/透明度（供 NPC 虚化使用）。

### 4.6 `Button` / `SpecialButton`（按钮）

- `Button`：三态（Off / On / Click），分别加载三张纹理；支持鼠标悬停、按下、释放与 `Q` 键触发；`std::function<void()> callback` 回调；可绑定点击音效。
- `SpecialButton`：两态（Off / Pressed），用于 F 键提示；同时支持鼠标点击与 `F` 键按下/释放触发。

### 4.7 `Camera`（摄像机）

- 封装 `sf::View`，支持设置尺寸、位置、边界（`setBounds`）。
- `followTarget` 将摄像机中心设为目标点。
- `clampToBounds` 将摄像机中心限制在边界内（考虑半宽/半高，防止越界）。
- `applyTo` 将视图应用到窗口。

### 4.8 `Player`（街道玩家）

- 状态机：`Idle` / `Walking` 两种状态，切换时停止旧动画、播放新动画。
- `handleInput` 用实时按键检测（`sf::Keyboard::isKeyPressed`）设置水平速度，`A` 向左、`D` 向右。
- `update` 更新位置并施加移动边界约束（半宽 16 像素），同步翻转朝向（`facingRight`）与动画。
- 站立动画 9 帧（10 fps），行走动画 12 帧（12 fps），缩放至 32×32 显示。

### 4.9 `NPC` / `NPCManager`（NPC 系统）

- `NPC`：两种类型（1/2），分别加载不同帧数（7/6 帧站立、12 帧行走）的精灵表；支持透明度（`opacity`，用于与玩家重叠时虚化）；`isOffScreen` 判断是否超出可视范围。
- `NPCManager`：
  - 定时（默认 1 秒）从左右两侧随机生成 NPC，随机类型、Y 坐标（生成区域 Y 94–121）、行走方向与速度。
  - 每帧更新所有 NPC，移除屏幕外的 NPC。
  - `checkPlayerCollision`：与玩家 AABB 重叠时降低 NPC 透明度（下限 100），否则逐渐恢复（上限 255）。

## 5. 关键系统实现

### 5.1 视图缩放与分辨率适配

`Game::updateScale()` 计算窗口尺寸与 320×180 基准分辨率的 `min(scaleX, scaleY)`，然后设置 viewport 为居中的等比例区域，实现任意窗口尺寸下的等比缩放 + 黑边。

### 5.2 场景切换机制

采用「请求-确认」两阶段，避免在事件分发过程中直接 `delete` 当前场景：

1. 场景内部调用 `requestSceneChange(target)` 设置标志。
2. `Game::processEvents` 处理完一个事件后调用 `SceneManager::checkSceneChange()`。
3. `SceneManager` 检测到标志后调用 `changeScene` 真正切换。

### 5.3 粒子系统

多个小游戏各自实现了轻量粒子数组（固定大小，循环复用）：

- **Game1**：300 个粒子，含类型（普通/火焰/冲击波/血液）、旋转、旋转速度，用于打击特效。
- **Game2**：100 个粒子，用于尾气与碰撞火花，带 `z` 深度透视。
- **Game3**：150 个粒子，用于砖块碎裂、金币、受击。
- **Game5**：500 个粒子 + 200 个拖尾节点，用于吃食、碰撞、蛇身光轨。

通用模式：遍历固定数组寻找 `!active` 槽位复用，`life` 递减至 0 后置为非活跃。

### 5.4 程序化音效生成

Game1、Game3、Game5 不依赖外部音频文件，运行时通过数学波形合成 `sf::SoundBuffer`：

- **Game1**：拳/脚/受击/必杀/KO/格挡 6 种，通过正弦波 + 噪声 + 衰减包络生成。
- **Game3**：跳跃/金币/受击/道具 4 种。
- **Game5**：独立的 `SnakeSoundManager` 类，生成吃食/道具/受击/游戏结束/移动 5 种。

合成方式：循环采样生成 `std::vector<sf::Int16>` 或 `sf::Int16[]`，调用 `sf::SoundBuffer::loadFromSamples(samples, count, channels=1, sampleRate=44100)`。

### 5.5 碰撞检测

- **AABB 碰撞**（通用）：`x1 < x2+w2 && x1+w1 > x2 && y1 < y2+h2 && y1+h1 > y2`。
- **Game3 平台碰撞**：采用「最小穿透深度」分离轴判断上下左右，正确处理落地、顶砖、撞墙。
- **Game1 攻击判定**：`Hitbox` 结构（位置/尺寸/伤害/击退/存活时间/是否命中/拥有者），命中后置 `hasHit` 防止重复结算。
- **Game4 迷宫碰撞**：网格坐标检测，仅允许进入 `worldMap == 0`（空地）或 `== 2`（终点）的格子，移动时分 X/Y 轴分别检测（实现贴墙滑动）。

### 5.6 光线投射（Game4 的 3D 渲染）

`Game4::castRays()` 实现经典 Raycasting：

1. 从 `player.angle - FOV/2` 开始，以 `FOV / NUM_RAYS`（80 条射线）步进。
2. 每条射线以 0.05 步长前进，直到命中墙或达到最大深度 20。
3. 用 `atan2` 判断命中墙面为水平或垂直（影响明暗）。
4. 鱼眼校正：`distance *= cos(rayAngle - player.angle)`。
5. 由距离计算墙面高度 `ceiling/floor`，绘制天花/墙/地板三条竖带。
6. 终点墙面（`worldMap == 2`）使用脉冲金色高亮。

### 5.7 状态机

- **Player**：`Idle / Walking` 两态。
- **Game1 Fighter**：`IDLE / WALK_FORWARD / WALK_BACKWARD / JUMP / CROUCH / LIGHT_PUNCH / HEAVY_PUNCH / LIGHT_KICK / HEAVY_KICK / SPECIAL_MOVE / BLOCK / HIT / KNOCKED_DOWN / GET_UP / WIN / LOSE` 十六态。
- **Game1 AI**：`aiState`（防御/进攻/特殊）+ 定时决策（0.3 秒）的规则型 AI。

## 6. 代码约定与注意事项

- 源码注释为中英文混合，包含较多开发期调试日志（`std::cout`）。
- 资源路径统一为 `../assets/...`，要求运行时工作目录为 `bin/`。
- 小游戏内返回按钮采用「延迟初始化」（首次 `render()` 时初始化），原因在于按钮纹理需在渲染上下文建立后加载。
- `GameBase` 的子类中，`isGameRunning()` 约定为 `!gameOver && !gamePaused`；`getScore()` 各游戏含义不同（见各游戏设计）。
- `Game4` / `Game5` 使用固定大小的静态数组管理实体（`int worldMap[16][16]`、`snake[MAX_SNAKE_LENGTH]` 等），其余游戏多使用 `std::vector`。

## 7. 构建指南

### 7.1 依赖

- SFML 2.x（头文件与库）
- MinGW-w64 g++（或兼容 GCC 的编译器）
- OpenAL 运行库（随 `bin/openal32.dll` 分发）

### 7.2 编译命令（示例）

```bash
cd src
g++ -std=c++17 -O2 \
    main.cpp Game.cpp SceneManager.cpp Scene1.cpp Scene2.cpp Scene3.cpp \
    Button.cpp SpecialButton.cpp Camera.cpp Player.cpp NPC.cpp NPCManager.cpp \
    SpriteSheet.cpp ResourceManager.cpp Game1.cpp Game2.cpp Game3.cpp \
    Game4.cpp Game5.cpp TestScene.cpp TestSpriteScene.cpp \
    -I<SFML头文件目录> -L<SFML库目录> \
    -lsfml-graphics -lsfml-audio -lsfml-window -lsfml-system \
    -o ../bin/ArcadeSimulator.exe
```

> 也可使用 CMake 或 IDE（如 Visual Studio Code + MinGW）组织编译，项目当前未附带构建脚本。

### 7.3 运行

将编译产物（`ArcadeSimulator.exe`）与所需 DLL（`sfml-*-2.dll`、`openal32.dll`、`libgcc_s_seh-1.dll`、`libstdc++-6.dll`、`libwinpthread-1.dll`）一起放在 `bin/` 目录，保持 `assets/` 位于项目根目录（即 `bin/` 的上一级），从 `bin/` 启动即可。

## 8. 如何扩展

### 8.1 添加新场景

1. 在 `Scene.h` 的 `SceneType` 枚举中添加新类型。
2. 新建 `SceneX` 类继承 `Scene`，实现 `handleInput/update/render`。
3. 在 `Game::Game()` 构造函数中 `sceneManager.addScene(SceneType::SceneX, std::make_unique<SceneX>())` 注册。
4. 在任意场景中调用 `requestSceneChange(SceneType::SceneX)` 切换。

### 8.2 添加新小游戏

1. 新建 `GameX` 类继承 `GameBase`，实现全部纯虚接口。
2. 在 `Scene3::selectGame(int)` 中添加分支：创建 `GameX` 实例、`init()` 后赋给 `currentGame`，并置 `playingGame = true`。
3. 在 `assets/images/scene3/` 下准备对应按钮三态图片（若复用第 6 个按钮则直接绑定）。

### 8.3 复用组件

- 需要缓存资源：统一使用 `ResourceManager::getInstance().loadXxx(path)`。
- 需要按钮：使用 `Button`（三态）或 `SpecialButton`（F 键触发）。
- 需要精灵动画：使用 `SpriteSheet`（注意 `load(path, frameW, frameH, frames, fps)` 与 `setOriginCenter()`）。
